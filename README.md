# Fashion Sales Data Analysis

## Project Overview
This project analyzes fashion sales data to identify sales trends, customer purchasing patterns, product performance, and business opportunities.

## Objectives
- Clean and prepare fashion sales data for analysis.
- Answer 14 business questions using PostgreSQL.
- Analyze sales performance and customer purchasing patterns.
- Create visualizations to communicate findings.
- Provide data-driven business recommendations.

## Tools Used
- **Python:** Data cleaning, analysis, and visualization.
- **Jupyter Notebook:** Documenting the analysis workflow.
- **PostgreSQL:** Querying the sales database.
- **Pandas:** Data manipulation.
- **Matplotlib and Seaborn:** Data visualization.

## Project Structure
- `Notebook/` — Jupyter Notebook containing data understanding, cleaning, analysis, visualizations, insights, and recommendations.
- `SQL/` — SQL queries used to answer 14 business questions.
- `Visualization/` — Ten saved charts.
- `data/` — CSV datasets used during the project.

## Key Findings
The analysis examines sales performance, customer purchasing behavior, sales channels, payment methods, and the relationship between discounts and quantity sold.

## Business Recommendations
The project provides recommendations based on the results of the analysis, with the goal of supporting better sales and marketing decisions.
